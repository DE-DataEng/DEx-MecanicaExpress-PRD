# 📊 Estudo de Viabilidade
## Projeto: Mecânica Express
Sistema de Gestão para Oficinas Mecânicas

---

# 🎯 1. Objetivo do Projeto

Desenvolver um sistema acessível, simples e eficiente para gestão de oficinas mecânicas, contemplando:

- Cadastro de clientes
- Controle de veículos
- Gestão de ordens de serviço
- Orçamentos
- Controle de peças
- Gestão financeira
- Controle de funcionários e mecânicos

---

# 📈 2. Análise de Mercado

## 📌 Público-Alvo
- Oficinas mecânicas pequenas e médias
- Empresas com 1 a 10 funcionários
- Negócios que ainda utilizam controle manual ou sistemas limitados

---

## 📊 Cenário Atual

Grande parte das oficinas:

- Utiliza papel ou planilhas Excel
- Não possui controle financeiro estruturado
- Não mantém histórico de clientes e serviços
- Possui dificuldades no controle de estoque

---

## 💡 Oportunidade

Desenvolver um sistema:

- Simples de usar
- Com baixo custo mensal
- Específico para o segmento automotivo
- Acessível via desktop e web

---

# ⚠️ 3. Problemas Identificados

| Problema | Consequência |
|---------|-------------|
| Controle manual de OS | Erros e retrabalho |
| Falta de controle financeiro | Prejuízo financeiro |
| Ausência de histórico de clientes | Perda de fidelização |
| Orçamentos desorganizados | Perda de vendas |
| Controle de estoque ineficiente | Falta ou excesso de peças |

---

# 🧠 4. Solução Proposta

Sistema integrado com os seguintes módulos:

## 📦 Módulos Principais

- 👤 Clientes
- 🚗 Veículos
- 🛠️ Ordens de Serviço
- 💰 Orçamentos
- 📦 Peças / Estoque
- 📊 Financeiro
- 👨‍🔧 Funcionários / Mecânicos

---

## 🧩 Diferenciais do Produto

- Interface moderna e intuitiva
- Facilidade de uso (baixo aprendizado)
- Sistema leve e rápido
- Foco total no segmento de oficinas
- Acessível financeiramente

# 🧪 8. Estratégia de Validação

Aplicar questionário para oficinas com perguntas como:

- Como controla sua oficina hoje?

### 2. Entrevistas Diretas

---

### 3. Protótipo

- Apresentar para potenciais clientes

---

### 4. Validação de Pagamento

Pergunta-chave:

> "Você pagaria R$ 29/mês por um sistema que resolvesse esses problemas?"
